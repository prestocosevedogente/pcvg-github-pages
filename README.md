# Presto Cose, Vedo Gente

Sito ufficiale di Presto Cose, Vedo Gente - l’Oggettoteca di Modena.

Il sito è realizzato in HTML, CSS e JavaScript vanilla ed è predisposto per la pubblicazione gratuita tramite GitHub Pages.

## Caratteristiche

- sito statico senza WordPress, PHP o database;
- HTML5 semantico;
- CSS condiviso;
- JavaScript vanilla;
- design responsive;
- navigazione accessibile;
- immagini salvate localmente;
- menu mobile;
- collegamenti social;
- collegamenti alle associazioni aderenti;
- pagine dedicate a catalogo, regolamento e privacy;
- compatibilità con GitHub Pages.
